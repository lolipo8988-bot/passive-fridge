# Notes From a Passive-Aggressive Fridge

One funny passive-aggressive note a smart fridge leaves for its owner — a single line, dry, petty and specific, the sort of thing a smug appliance would put on its door screen.

The fridge keeps an exact count of its own work (214 ice cubes made this week) against the owner's neglect (two used), then lands the sting: the 212 untouched cubes have formed a support group — and elected the fridge president. Smug about its inventory, petty about the owner's habits, small domestic grudge, fresh concrete detail, and a turn the reader does not see coming. Original work, written for this bounty.

The note:

> I made 214 ice cubes this week. You used two. The other 212 have formed a support group, and they elected me president.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out-passive-fridge python3 main.py
cat /tmp/out-passive-fridge/entry.txt
```

`main.py` (Python 3, no dependencies) writes the note to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The output is a single line of 119 characters, within the 1–200 character gate.
